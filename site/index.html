Syspeek

Linux · C++20 · Qt 6

A tiny, always-on-top HUD for the app you're focused on.

No more hunting through top. Syspeek follows the window you're using and shows that application's CPU and memory — plus optional Docker and Kubernetes health — in a compact panel that stays out of your way.

curl -fsSL https://raw.githubusercontent.com/codeafridi/Syspeek/main/install.sh | sh

Installs a self-contained build (Qt bundled — no compiler needed) and starts at login. Needs x86-64 and glibc ≥ 2.34.

What it shows

Focused application

The window you're using right now — its PID, CPU percentage, and resident memory — updated live.

Docker

Running container count, and flags for unhealthy, restarting, and recently exited containers.

Kubernetes

Problem pods (CrashLoopBackOff, image-pull failures, OOMKilled) and deployments with too few ready replicas, from your current kubectl context.

Works where you are

GNOME, KDE, Sway, niri, and X11 out of the box; other Wayland compositors run fine and simply show no-focus.

Both integrations are optional and run off the UI thread, so a missing tool never blocks the overlay.

Compatibility

Built and tested on Ubuntu, Debian, Fedora, RHEL 9 clones, openSUSE, Arch, and Alpine. The installer ships Qt 6 with the app, so it also runs on distros that don't package Qt 6 (openSUSE Leap, Amazon Linux 2023).

  • Portable install — Linux, x86-64, glibc ≥ 2.34.
  • From source — any distro with Qt 6 packages (RHEL family uses EPEL; Alpine uses musl).
  • Controls — syspeek stop, syspeek disable, syspeek update, syspeek uninstall.
